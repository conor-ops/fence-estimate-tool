# Fence Estimate Tool

AI-powered fence material and cost estimation service. Send fence dimensions and parameters; get an itemized estimate (posts, rails, pickets, concrete, gates, labor, total cost) generated by **Gemini 2.5 Flash** via **Vertex AI**.

Built for **208 Fence and Gate**.

## API

### `GET /`

Interactive landing page for the estimate service with a live, client-side fence preview and links to the API docs and health check.

### `POST /estimate`

**Request body:**

```json
{
  "length_ft": 100,
  "height_ft": 6,
  "material_type": "cedar",
  "gate_count": 2,
  "terrain": "flat"
}
```

**Response body:**

```json
{
  "line_items": [
    {"item": "4x4 cedar posts (8 ft)", "quantity": 14, "unit_cost": 12.50, "total_cost": 175.00},
    ...
  ],
  "labor_hours": 24.5,
  "total_material_cost": 1250.00,
  "total_labor_cost": 980.00,
  "grand_total": 2230.00,
  "notes": "Assumptions: posts every 8 ft, 2 bags concrete per post...",
  "estimated_installation_days": 3
}
```

### `GET /health`
Health check endpoint for Cloud Run.

## Run Locally

### Prerequisites
- Python 3.11+
- Google Cloud Application Default Credentials (ADC) configured:
  ```bash
  gcloud auth application-default login
  ```
- The GCP project `gen-lang-client-0999709111` must have the Vertex AI API enabled.

### Steps

```bash
# Clone the repo
git clone https://github.com/conor-ops/fence-estimate-tool.git
cd fence-estimate-tool

# Create virtualenv and install deps
python -m venv .venv
source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# Set environment variables
cp .env.example .env
export GOOGLE_CLOUD_PROJECT=gen-lang-client-0999709111
export VERTEXAI_LOCATION=us-central1

# Run
uvicorn main:app --host 0.0.0.0 --port 8080
```

### Test the endpoint

```bash
curl -X POST http://localhost:8080/estimate \
  -H "Content-Type: application/json" \
  -d '{"length_ft": 100, "height_ft": 6, "material_type": "cedar", "gate_count": 2, "terrain": "flat"}'
```

## Deploy to Google Cloud Run

### 1. Set project and enable APIs

```bash
gcloud config set project gen-lang-client-0999709111
gcloud services enable run.googleapis.com \
  cloudbuild.googleapis.com \
  artifactregistry.googleapis.com \
  aiplatform.googleapis.com
```

### 2. Create Artifact Registry repo (one-time)

```bash
gcloud artifacts repositories create fence-estimate-repo \
  --repository-format=docker \
  --location=us-central1
```

### 3. Build & deploy

```bash
# Deploy directly from source (builds the Docker image automatically)
gcloud run deploy fence-estimate-tool \
  --source . \
  --region us-central1 \
  --port 8080 \
  --memory 512Mi \
  --cpu 1 \
  --timeout 120 \
  --set-env-vars GOOGLE_CLOUD_PROJECT=gen-lang-client-0999709111,VERTEXAI_LOCATION=us-central1 \
  --no-allow-unauthenticated
```

Or build and push manually:

```bash
# Build
gcloud builds submit --tag us-central1-docker.pkg.dev/gen-lang-client-0999709111/fence-estimate-repo/fence-estimate-tool .

# Deploy
gcloud run deploy fence-estimate-tool \
  --image us-central1-docker.pkg.dev/gen-lang-client-0999709111/fence-estimate-repo/fence-estimate-tool \
  --region us-central1 \
  --port 8080 \
  --set-env-vars GOOGLE_CLOUD_PROJECT=gen-lang-client-0999709111,VERTEXAI_LOCATION=us-central1
```

### 4. Get the deployed URL

```bash
gcloud run services describe fence-estimate-tool --region us-central1 --format 'value(status.url)'
```

### Test deployed service

```bash
curl -X POST <DEPLOYED_URL>/estimate \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $(gcloud auth print-identity-token)" \
  -d '{"length_ft": 100, "height_ft": 6, "material_type": "cedar", "gate_count": 2, "terrain": "flat"}'
```
